# Tomatin Code Lab

Plataforma web gratuita para practicar Programacion I y II con misiones
originales, humor chileno y una estetica de terminal. El proyecto esta pensado
para ejecutarse como sitio estatico en GitHub Pages.

> Proyecto independiente. No esta afiliado ni respaldado por MIT. El temario
> toma como referencia conceptos habituales de cursos universitarios de
> introduccion a ciencias de la computacion; todos los enunciados y recursos de
> esta plataforma son originales.

## Estado

En construccion. La primera version incluira:

- rutas de Programacion I y II;
- ejercicios autocorregibles y desafios de codigo;
- progreso, puntos y ranking local;
- acceso de estudiante y panel administrativo de demostracion;
- easter eggs y referencias chilenas;
- despliegue automatico en GitHub Pages.
